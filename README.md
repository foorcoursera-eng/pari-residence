# PARI Residence — сайт pari-residence.uz

Сайт жилого квартала PARI Residence в Самарканде: главная со сценами по образцу era-residence.com,
каталог из 1186 квартир с фильтрами, страницы 62 планировок с планом этажа, четыре языка (RU / UZ / EN / FR),
приём заявок в Telegram отдела продаж.

## Запуск

```
npm install
npm run dev       # http://localhost:4321
npm run build     # сборка в dist/
```

Нужен Node.js 22.12 или новее.

## Выкладка

Сайт живёт на Vercel, проект `pari-residence` (домен pari-residence.uz). Выкладывает владелец:

```
npm run deploy              # боевой сайт pari-residence.uz
npm run deploy -- redesign  # проверочный pari-redesign.vercel.app
```

Переменные окружения (только в настройках проекта Vercel): `TG_BOT_TOKEN`, `TG_CHAT_ID`.
После их смены сайт нужно перевыложить.

Правила работы с кодом и устройство проекта — в [CLAUDE.md](CLAUDE.md).

## Работа в облаке через GitHub

Актуальные исходники домена на 26.09.2026: ветка `current-site-2026-09-26`.
Ветка `main` сохраняет предыдущую версию сайта.

В облачной среде выберите эту ветку, Node.js 22.12+ и выполните:

```sh
npm ci
npm run build
npm run dev -- --host 0.0.0.0
```

Для проверки интерфейса ключи не нужны. Отправка заявок требует серверного
окружения Vercel и переменных TG_BOT_TOKEN / TG_CHAT_ID; секреты в GitHub не хранятся.
Исправления создавайте отдельными ветками от актуальной версии.
`npm run deploy` публикует сайт: для проверки ошибок запускать его не требуется.
