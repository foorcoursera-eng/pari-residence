# PARI Residence — лендинг

Статический одностраничный сайт (HTML/CSS/JS) + одна serverless-функция для приёма заявок в Telegram (и, опционально, в CRM Macroserver/MACRO).

## Структура

```
index.html        — вся разметка страницы
styles.css         — стили (шрифты Tenor Sans + Jost подключены локально, без внешних CDN)
script.js          — фильтр планировок, форма заявки, анимации появления
api/lead.js        — serverless-функция: принимает заявку, пересылает в Telegram и (при наличии ключей) в Macroserver
assets/fonts/      — файлы шрифтов (.woff2)
```

## 1. Посмотреть локально

Просто откройте `index.html` в браузере — сайт полностью статический и не требует сборки.
Форма заявки при этом работать не будет (нет сервера) — это нормально, до деплоя на Vercel.

## 2. Выложить в интернет (GitHub + Vercel, бесплатно)

1. Создайте новый репозиторий на [github.com](https://github.com) и загрузите туда содержимое этой папки.
2. Зайдите на [vercel.com](https://vercel.com), войдите через GitHub.
3. «Add New… → Project» → выберите этот репозиторий → Deploy.
   Никаких дополнительных настроек не требуется — Vercel сам увидит `index.html` и папку `api/`.
4. Через минуту сайт будет доступен по адресу вида `https://pari-residence.vercel.app`.

При каждом обновлении кода в GitHub сайт будет пересобираться и публиковаться автоматически.

## 3. Настроить приём заявок в Telegram

1. В Telegram напишите **@BotFather** → `/newbot` → следуйте инструкциям → получите **токен бота**.
2. Добавьте бота в нужный чат/канал (или начните с ним личный диалог) и узнайте **chat_id**:
   - самый простой способ — добавить бота [@userinfobot](https://t.me/userinfobot) в тот же чат, он покажет ID чата;
   - либо отправить боту любое сообщение и открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет `chat.id`.
3. В настройках проекта на Vercel: **Settings → Environment Variables** — добавьте:
   - `TG_BOT_TOKEN` — токен бота из шага 1
   - `TG_CHAT_ID` — id чата из шага 2
4. Нажмите **Redeploy**, чтобы переменные применились.

Заявки с сайта будут приходить в этот чат сообщением с именем, телефоном и выбранным форматом квартиры.

## 4. Подключить CRM Macroserver / MACRO (когда будет готов админ-доступ)

`Macroserver.uz` — это узбекская региональная инсталляция платформы **MACRO** (она же MacroCRM), CRM/ERP для застройщиков. У неё есть официальный API специально для приёма заявок с сайта — это стандартный, документированный сценарий, не самописный хак.

Код для этого уже подготовлен в `api/lead.js` (функция `forwardToMacro`) и **ничего не делает, пока не заданы переменные окружения** — значит, ничего не сломается и не нужно менять код позже.

Что должен сделать **администратор** аккаунта Macroserver (обычный пользователь этого сделать не может):
1. Зайти в кабинет Macroserver → **Компания → Интеграции**.
2. Зарегистрировать домен сайта и получить `app_secret` (защищённый ключ интеграции).
3. Передать вам: `app_secret` и домен, под которым он зарегистрирован.

Дальше в Vercel: **Settings → Environment Variables** добавить:
- `MACRO_APP_SECRET` — ключ из шага 2
- `MACRO_DOMAIN` — домен сайта (тот же, что зарегистрирован в CRM)
- `MACRO_API_BASE` — обычно не нужно; по умолчанию используется `https://api.macroserver.uz/estate/request/`. Задайте вручную, только если администратор Macroserver скажет другой адрес API.

После `Redeploy` заявки начнут параллельно уходить и в Telegram, и в Macroserver — без каких-либо изменений на сайте.

> Названия полей запроса (`name`, `phone`, `action` и т.д.) взяты из документации MACRO по интеграции с сайтом. У разных версий кабинета они могут немного отличаться — при первом реальном подключении стоит свериться с разделом «Интеграции» в самом кабинете Macroserver и, если нужно, поправить пару строк в `forwardToMacro()`.

## 5. Подключить домен `.uz`

1. Купите домен у любого регистратора `.uz` (например, через local-реселлера или напрямую в реестре).
2. В проекте на Vercel: **Settings → Domains** → добавьте ваш домен.
3. Vercel покажет DNS-записи, которые нужно прописать у регистратора домена (обычно A-запись или CNAME).
4. После обновления DNS (может занять от пары минут до суток) сайт откроется по вашему домену.

Когда в пятницу придут официальные фото/рендеры — можно заменить эти файлы на новые (те же имена — ничего в коде менять не нужно) или добавить в галерею.
- Проверить и при необходимости уточнить цифры (площадь территории, озеленение — в исходных документах застройщика встречались расхождения между таблицами).
- Указать реальный адрес на карте (сейчас используется приблизительный поиск по названию улицы) и контактный Telegram-канал в футере, если он есть.
